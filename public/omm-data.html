云同步
未配置 Supabase
Project URL
Publishable Key
只填 Supabase Publishable key，不要把 service_role / secret key 放进页面
Auth 邮箱
只保存邮箱地址用于登录；密码仅在勾选“记住密码”后保存到本机
账号与密码
这个页面不提供注册请先登录 Supabase Dashboard，在 Authentication → Users 中创建一个 Auth 用户，然后使用该用户的邮箱和密码登录本应用
登录与同步
登录时无需再次输入账号，账号邮箱来自连接设置，下面只需要输入密码
密码
密码用于 Supabase Auth 验证和客户端 AES 解密。勾选“记住密码”后只存在本机浏览器的 LocalStorage 里，不会上传到云端
同步策略
手动同步：只在点击同步按钮时与云端交换数据
SQL 编辑器
Supabase Auth 负责身份验证，RLS 负责用户隔离；数据表内容上传前在浏览器端使用 AES-GCM 加密。应用只使用 Publishable key，不需要 service_role / secret key
开启云同步前请注意
开启后，本页的任何改动都会立刻写入云端并覆盖此前保存的云端数据。
云端不会保留任何历史记录的备份，误删除、误改动都无法回滚，并且会立刻影响到所有登录同一账号的设备。
