# OMM-ZEN v1.0.14 · 文档脱敏工具

本次只更新 **文档脱敏工具（OMM-Redact）**，其余应用与插件保持原版本不变。

## 更新内容

- **原生 DOCX 版式**：直接解析 OOXML，保留纸张、页边距、字体、表格、图片、页眉页脚、编号与分页点；图片按 `wp:anchor` 的真实偏移回到左右侧栏。
- **两种导入方式**：打开 DOCX 时可选择「网页版式」或「转 PDF 导入」；后者调用本机 LibreOffice / AbiWord，版式由真实办公排版引擎生成。
- **PDF 转换引擎设置**：可填写 LibreOffice / AbiWord / Ghostscript 路径，支持自动检测、保存、重新检测与“测试转换”。
- **PDF 工具（Ghostscript）**：压缩、修复、转 PDF/A、提取页码范围、导出页面图片、合并多个 PDF；显示处理前后体积变化。
- **页面缩放**：网页版式与 PDF 导入都支持工具栏 `+ / -`，40%–400%，遮罩坐标不漂移。
- **细节修复**：目录域（TOC/PAGEREF）恢复显示；`w:cr` 软换行；表格边框缺色补黑、默认单元格内边距；并排图片按真实偏移定位；中英文分别使用 Times New Roman / 宋体。

## 更新方式

- **集成器里**：插件管理器会发现「文档脱敏工具 1.0.14」并更新插件。
- **独立版 OMM-Redact.exe**：请从本 Release 下载替换（catalog 全局版本保持不变，避免其它应用收到无法完成的更新提示）。
- 其它应用、框架版工作台、安装器均未改动。
