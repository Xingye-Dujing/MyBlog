# OMM-ZEN v1.0.16（工作台更新逻辑与体验修复）

本版本为全量发布（版本号在所有组件统一为 **1.0.16**），重点修复了“高版本被误提示更新到低版本”的降级误报，并纳入工作台近期的体验改进。

## 核心修复：更新检查不再把高版本提示为“可更新到低版本”

此前存在版本号来源不统一 + 字符串比较的问题：`catalog.json` 顶层 `version` 可能陈旧（如停在 1.0.9），而框架/组件实际已是 1.0.15；同时插件的 `update_available` 用字符串 `!=` 判断。结果是本地内置 1.0.15 的程序，可能被提示“发现新版本 1.0.9”——方向反了，实际是一次降级。

- 新增**统一的版本比较入口**（`plugin_specs.is_newer` / `version_key`），采用严格数字大小比较（`>`），忽略 `v` 前缀，支持多段版本号，`1.10 > 1.2` 不再被字典序误判。
- 自更新检查改为拿“实际要安装的组件版本”（框架 / 应用 / DMG）与内置版本比较，顶层目录版本仅在组件无版本时兜底；目录版本无论陈旧还是虚高，都不会再触发错误的更新提示。
- 工作台插件目录与“在线插件”面板统一改用数字比较：本地较新时显示“重新安装”而非“更新”，不再出现高版本向低版本更新的误导。

## 工作台体验改进

- **定时快照**：设置项扩展为 12 档（5/10/15/30/45 分钟、1/2/4/6/12/24 小时 + 关闭），提示文案随档位友好显示。
- **存档批量管理**：存档面板支持逐项勾选与全选，批量删除；选择集随可见项自动收敛，避免误删。
- **深色模式柔化**：ZENPLAN 深色主题文字与边框降低刺眼感，长时间阅读更舒适。

## 更新方式

- 完整版 `OMM-ZEN.exe` / 框架版：通过 `catalog.json` 自更新到 1.0.16。
- 在线安装器 `OMM-ZEN-Setup.exe`：全新安装默认获取 1.0.16 组件。
- 独立产品 EXE 与插件包：从本 Release 下载覆盖，或在集成器“插件管理”内更新。
