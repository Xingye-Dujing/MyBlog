# OMM-ZEN v1.0.13 · 集成器外观与更新体验

本次只更新 **OMM-ZEN 集成器（工作台壳）**，框架版本 1.0.10。
产品插件与其它 11 个独立程序保持原版本不变，全局更新通道仍为 1.0.9，不会打扰它们。

## 更新内容

- **存档弹窗点击外部即关闭**：点工作台空白、标签栏或产品页面都会收起存档面板；点「存档」按钮本身不会误关，方便连续操作。
- **圆角真正管住所有边框**：「所有应用」面板、存档面板、设置 / 插件面板里的输入框、按钮、标签页、列表、提示条等，全部跟随「圆角」设置，不再有漏掉的直角。
- **主题色更丰富**：12 个预设（新增珊瑚、蜜桃、薄荷、天青、紫罗兰、樱粉、青柠、靛蓝），并支持**自定义十六进制**（`#RGB` / `#RRGGBB`，深浅色自动派生提亮色）。主题色现在驱动标签、Dock、按钮、弹窗、开关、命令面板、提示条、存档与共享面板等全部区域。
- **不再出现浏览器原生弹窗**：确认框、下拉候选、悬浮提示全部换成 OMM-ZEN 样式；选择完成后不再保留聚焦框，键盘操作仍保留可见焦点。
- **插件管理的「更新」标签更完整**：除了工作台框架，还会逐个汇报每个插件的本地版本 → 目录版本、是否有更新，并可直接更新。
- 深色主题下切换强调色此前不生效的问题已修复。

## 获取方式

- 从本 Release 下载 `OMM-ZEN.exe`，覆盖原程序即可；框架版下载 `OMM-ZEN-Framework-win64.zip` 解压替换。
- 本次**不提升全局 catalog 版本**，因此旧版集成器不会弹出自动更新提示——这是为了不干扰其它 11 个产品（它们的 1.0.9 更新无法完成）。升级后程序内版本为 1.0.10。
- 用户数据（保存路径、快照、共享空间、页面缩放）不受影响。

## 文件

- `OMM-ZEN.exe`（完整离线集成器 1.0.10）
- `OMM-ZEN-Framework-win64.zip`（框架版集成器 1.0.10）
- `catalog.json`（全局 version 1.0.9，仅集成器条目指向 1.0.10）
