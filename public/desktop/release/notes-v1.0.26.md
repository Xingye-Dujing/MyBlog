# 静书房 v1.0.26（AI 工作区 · 知识卡片生态 · 全局联动与统一守卫）

本版本为全量发布，版本号在所有组件统一为 **1.0.26**。自 v1.0.17 以来共 59 次提交，涵盖新产品、工作台联动、图表单一来源、以及一批安全与稳定性修复。

## 新产品与新能力

- **静书房 AI 工作区**（新插件 `ai`）：产品技能、格式模板与代码校验；AI 读取用户真实产品数据，消息监听校验父窗口与来源，统一隐私过滤覆盖工具、技能与上下文。
- **免费联网智能搜索**（新插件 `search`）：搜索历史升级为可检索知识库，支持一键存卡片与 ZenFlow 规则模板。
- **知识卡片生态**：ZenPack 工作区包、ZenFlow 可视化流程编辑器、ZenCard、ZenClip、ZenReview、ZenBackup 等新插件；所思所想的知识卡片引用块、内嵌图表与时间机器。
- **ZenReview 联动**：Writer 引文审查链接与今日审查画布，ZenReview 可从工作台拉取。

## 工作台（Hub）

- 新增 **今日面板**，聚合各产品数据；新增 **原生知识图谱面板** 与可视化共享通道的数据流面板。
- Cmd+K 升级：模糊匹配、使用频率加权与本地即时命令（计算 / 日期 / 进制）。
- 产品注册表改为 `plugin_specs.py` 单一真源。

## 联动链路

- 数据工作台一键出图到可视化图表 → 复盘快照 → 报告（Data → Viz → Report）。
- AI 学习包技能、搜索一键存卡片、ZenFlow 规则模板等跨产品联动。

## 图表单一来源

- 图表页改由 `zen viz-core` 单一来源生成并加防漂移守卫；子模块切换到 GitHub 地址并推进指针。

## 安全与质量

- 封堵样式白名单绕过、两处 `javascript:` 链接注入、实时上下文崩溃、危险 TeX 命令、WebDAV 重定向 SSRF 与跨域凭据丢弃。
- 脱敏备份不得作为本地恢复源，恢复写入键受限；补齐凭据泄露与权限校验缺口。
- AI 隐私过滤统一化；统一产品守卫新增资源可达、HTML 转义、可访问性、FORMAT 格式契约与分层版本/内容指纹检查。
- 新增 Playwright 真实浏览器端到端链路测试，并验证离线优先（阻断非本地网络后核心链路仍可用）。
- 修复前端消息丢失/重复打开、数据处理与状态同步、后端输入校验、窗口几何丢失、服务复用、账号隔离、信度行号对齐、可视化统计等问题。

## 更新方式

- 完整版 `OMM-ZEN.exe` / 框架版：通过 `catalog.json` 自更新到 1.0.26。
- 在线安装器 `OMM-ZEN-Setup.exe`：全新安装默认获取 1.0.26 组件。
- 独立产品 EXE 与插件包：从本 Release 下载覆盖，或在集成器“插件管理”内更新。
