# OMM-ZEN v1.0.11 · 所思所想

本次只更新 **所思所想（OMM-Writer）**，其余应用与插件保持 v1.0.9 不变。

## 更新内容

- **对齐基准迁移到悬浮对齐条**：选中一个节点设为基准后，左对齐、右对齐、水平/垂直居中、顶/底对齐都以基准节点为参照；基准节点原地不动。
- 悬浮对齐条最左侧新增「基准」按钮：有基准时点击清除，没有基准时用主选中节点设基准；右键节点也能「设为对齐基准 / 清除对齐基准」。
- 基准标记改为**单色**（黑色/白色描边 + BASE 小标签），不再使用紫色，也没有纯黑背景块。
- 统一尺寸也支持基准：有基准时按基准节点的宽度/高度统一；分布时基准节点保持不动。
- 排布菜单恢复为纯策略：智能 / 主线 / 分层 / 聚拢 / 径向 / 时间线，不再包含基准排布。
- 保留上一版的排布改进：节点实际尺寸、节点/连线互不遮挡、短连线、交叉数择优、框选局部排布避让他人连线等。

## 更新方式

- **集成器里**：插件管理器会自动发现「所思所想 1.0.11」并更新插件。
- **独立版 OMM-Writer.exe**：请从本 Release 下载替换（catalog 全局版本仍为 1.0.9，避免其它应用收到无法完成的更新提示）。
- 其它应用、框架版工作台、安装器均未改动。
