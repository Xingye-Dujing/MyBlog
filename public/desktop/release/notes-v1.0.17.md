# 静书房 v1.0.17（工作台更名「静书房」+ 规划器天数视图 + 画布基准恢复）

本版本为全量发布（版本号在所有组件统一为 **1.0.17**），包含工作台品牌更名、规划器新视图与所思所想的画布布局记忆。

## 工作台：中文名改为「静书房」

用户可见的品牌文案统一为「静书房」，纯中文、去掉 OMM-ZEN 英文字样：

- 窗口标题、托盘菜单与悬浮名、桌面快捷方式描述改为「静书房」。
- 工作台页面标题、品牌名、图标 alt 与「关于」弹窗同步更名。
- 在线安装器的标题、品牌名、框架名、完成提示与启动按钮同步更名。

技术标识（exe 文件名、安装/数据路径、User-Agent、framework 常量、发布资产名）保持不变，不影响构建、自更新与既有安装路径兼容。

## 工作台：修复日程页首次加载闪现手机布局「更多」

日程页首次加载时会短暂闪现手机布局的「更多」入口，现已修复。

## 规划器：新增独立「天数」视图

- 新增独立的「天数」页面，支持倒数 / 正计时两种记录方式。
- 提供网格与列表两种展示方式，可自由切换。

## 所思所想：画布「基准」一键恢复

- 画布新增「基准」一键恢复：切换或改动基准后，可一键回到记忆中的布局。
- 布局记忆随画布持久化，重启后仍可恢复。

## 更新方式

- 完整版 `OMM-ZEN.exe` / 框架版：通过 `catalog.json` 自更新到 1.0.17。
- 在线安装器 `OMM-ZEN-Setup.exe`：全新安装默认获取 1.0.17 组件。
- 独立产品 EXE 与插件包：从本 Release 下载覆盖，或在集成器「插件管理」内更新。

> 自本版起，「所思所想」插件版本跟随全局版本号（此前为独立的 1.0.x 线），所有插件包统一为 1.0.17。

## 文件

- 13 个 EXE（11 个产品 + 完整版工作台 + 在线安装器）
- `OMM-ZEN-Framework-win64.zip`（框架版 / 安装器用）
- `plugin-*.zip`（11 个插件包）、`plugin-template.zip`、`plugin-spec.md`
- `catalog.json`（tag=v1.0.17，version=1.0.17）
