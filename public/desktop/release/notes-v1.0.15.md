# OMM-ZEN v1.0.15（脱敏工具 / 工作台热修复）

本版本针对桌面端「文档脱敏工具」打开时报 **"当前环境不可用"** 与设置转换引擎路径时 **"路径错误"** 两个问题，做了根因修复并重建发布。

## 修复内容

### 1. 工作台（OMM-ZEN.exe）缺少脱敏后端路由 —— 根因
通过 OMM-ZEN 工作台打开文档脱敏工具时，页面请求 `/__omm/fs/docx2pdf`
与 `/__omm/fs/pdf/tool` 两个桌面 API；旧版工作台（v1.0.10 及更早）编译时
尚未包含这两个路由，导致请求整体失败，页面显示「当前环境不可用」。

- 重建 **OMM-ZEN.exe（完整工作台）**，内置当前 `omm_shared` 源码，
  已包含上述全部 `/__omm/fs/*` 桌面 API 路由。
- 重建 **OMM-ZEN-Framework-win64.zip**（框架版 / 在线安装器用），
  同样包含修复后的路由，确保全新安装也能正常使用脱敏导入。

### 2. Ghostscript 检测卡死 → 改用控制台构建
窗口化的 `gswin64.exe --version` 在本机会挂起 8–10 秒。
- 引擎探测与配置保存统一改用控制台构建 `gswin64c.exe`，
  「测试」与「保存」不再卡顿（实测 0.1s 返回版本号）。

### 3. 引擎路径输入更宽容，不再误报「路径错误」
保存 LibreOffice / AbiWord / Ghostscript 路径时：
- 自动去除首尾引号与结尾的路径分隔符（来自文件管理器复制粘贴的常见干扰）。
- 若粘贴的是一个**目录**，自动在该目录内寻找对应可执行文件。
- 路径不存在 / 不是可执行文件时，给出明确中文提示，而非笼统的「路径错误」。

### 4. 前端自诊断提示
脱敏页面新增环境自检：
- 以 `file://` 直接双击打开 HTML（未连接桌面服务）时，明确提示应通过
  OMM-Redact 桌面程序或 OMM-ZEN 工作台打开，而不是本地文件方式。
- fetch 失败时给出可读的错误原因，便于定位。

## 已包含的能力（沿用 v1.0.14）
- 原生 DOCX 版式渲染（纸张 / 页边距 / 字体 / 表格 / 图片 / 页眉页脚 / 分页点）。
- PDF 转换引擎设置（LibreOffice / AbiWord / Ghostscript），支持自动检测与测试。
- PDF 工具（Ghostscript）：压缩、修复、转 PDF/A、提取页码、合并等。
- 页面缩放 40%–400%，遮罩坐标不漂移。

## 更新方式
- 完整版 / 框架版工作台：通过 `catalog.json` 自更新（已发布 v1.0.15 的
  OMM-ZEN.exe 与框架包）。
- 独立版 **OMM-Redact.exe**：从本 Release 下载覆盖替换即可。
- 集成器内「插件管理」会发现 `plugin-redact-1.0.15.zip` 的新版本。
