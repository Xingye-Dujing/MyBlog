# OMM-ZEN v1.0.10 · 所思所想

本次只更新 **所思所想（OMM-Writer）**，其余应用与插件保持 v1.0.9 不变。

## 更新内容

- 新增 **排布基准节点**：设为基准后，基准节点原地不动，其它选中节点围绕它重排。
- 排布菜单新增「设为基准 / 围绕基准排布 / 清除基准」，右键节点同样可设基准；快捷键 `Ctrl+Shift+L`。
- 新增 **主线排布（SPINE）**：主流程居中一列，截图与说明贴着锚点左右堆叠，连线短、整齐。
- 局部排布 / 基准排布会把未选中节点之间的连线也当作障碍，并在全画布范围内重选端口、必要时改画绕行折线。
- 所有排布读取节点实际尺寸；节点与连线互不遮挡；智能排布加入连线交叉数评分，优先选择更少打结、连线更短的一版。
- 顶部并行节点（如“下载资源 / 创建目录”）围绕中线对称展开，父节点落在两者中间。

## 更新方式

- **集成器里**：插件管理器会自动发现「所思所想 1.0.10」并更新插件。
- **独立版 OMM-Writer.exe**：请从本 Release 下载替换（本次 catalog 全局版本仍为 1.0.9，避免其它应用收到无法完成的更新提示）。
- 其它应用、框架版工作台、安装器均未改动，仍使用 v1.0.9 资源。
