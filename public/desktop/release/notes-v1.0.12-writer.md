# OMM-ZEN v1.0.12 · 所思所想

本次只更新 **所思所想（OMM-Writer）**，其余应用与插件保持 v1.0.9 不变。

## 更新内容

- **基准可以任意选择**：悬浮对齐条最左侧的「基准」按钮改成选择面板，列出选区内的节点和画布上其它节点，点谁谁就是基准；不再只能取最后点选的那个。
- **Alt + 点击节点**：直接把该节点设为基准，再 Alt + 点一次取消；不改变当前多选。
- 面板底部有「清除基准」，右键节点菜单里的「设为对齐基准 / 清除对齐基准」保留。
- **基准是唯一参照，且一步都不动**：
  - 左 / 右 / 顶 / 底对齐：全部贴基准对应的边；
  - 水平 / 竖直居中：全部取基准的中线；
  - 统一宽度 / 高度：全部取基准的尺寸（基准被折叠时不会把别人压扁）；
  - 水平 / 竖直分布：以基准为原点，按原有的左右（上下）顺序向两侧等边距展开，基准保持在原处。
- 分布仍然优先沿用当前相邻间距（取正间距中位数，限制在 20–240），不会突然拉散或挤在一起；没有基准时保持原来的「首尾固定、中间等距」。
- **基准不必在选区里**：只选其它节点，对齐和分布照样以基准为参照。
- 基准标记继续使用单色描边 + BASE 小标签，不使用紫色或纯黑底。

## 更新方式

- **集成器里**：插件管理器会自动发现「所思所想 1.0.12」并更新插件。
- **独立版 OMM-Writer.exe**：请从本 Release 下载替换（catalog 全局版本仍为 1.0.9，避免其它应用收到无法完成的更新提示）。
- 其它应用、框架版工作台、安装器均未改动。
